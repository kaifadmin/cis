-------------practicle 4-------------------
Aim: Install Ansible and create a playbook to install Apache/Nginx web server automatically.
Practical Code:
Install Ansible and Create Playbook for Apache/Nginx
Step 1: Install Ansible (Ubuntu/Linux)
Run:
sudo apt update
sudo apt install ansible -y
Verify installation:
ansible --version
Create Apache Web Server Playbook
Step 2: Create Project Folder
mkdir ansible-webserver
cd ansible-webserver
Step 3: Create Inventory File
Create file:
hosts
Add:
[webservers]
localhost ansible_connection=local
Step 4: Create Apache Playbook
Create file:
apache.yml
Add:
---
- name: Install Apache Web Server
hosts: webservers
become: yes
tasks:
- name: Install Apache
apt:
name: apache2
state: present
update_cache: yes
- name: Start Apache Service
service:
name: apache2
state: started
enabled: yes
Step 5: Run Playbook
ansible-playbook -i hosts apache.yml
Step 6: Verify Apache
Open browser:
http://localhost
Apache default page will appear.
Nginx Playbook (Alternative)
Create file:
nginx.yml
Add:
---
- name: Install Nginx Web Server
hosts: webservers
become: yes
tasks:
- name: Install Nginx
apt:
name: nginx
state: present
update_cache: yes
- name: Start Nginx Service
service:
name: nginx
state: started
enabled: yes
Run:
ansible-playbook -i hosts nginx.yml
Check Service Status
Apache:
systemctl status apache2
Nginx:
systemctl status nginx

------------practicle 7----------------
Aim: Configure route tables and security groups for secure network communication.   
Practical Code:
1. Project structure
Inside your project (~/ansible-webserver), make sure you have:
~/ansible-webserver/
│── main.tf
│── variables.tf
│── terraform.tfvars
│── outputs.tf
Check:
cd ~/ansible-webserver
ls
2. Create / update main.tf
Open file:
nano main.tf
Paste this:
provider "aws" {
region = "ap-south-1"
}
# ------------------------
# VPC
# ------------------------
resource "aws_vpc" "main" {
cidr_block
= "10.0.0.0/16"
enable_dns_support = true
enable_dns_hostnames = true
tags = {
Name = "MyVPC"
}
}
# ------------------------
# Internet Gateway
# ------------------------
resource "aws_internet_gateway" "gw" {
vpc_id = aws_vpc.main.id
tags = {
Name = "MainGateway"
}
}
# ------------------------
# Public Subnet
# ------------------------
resource "aws_subnet" "public" {
vpc_id= aws_vpc.main.id
cidr_block= "10.0.1.0/24"
availability_zone
= "ap-south-1a"
map_public_ip_on_launch = true
tags = {
Name = "PublicSubnet"
}
}
# ------------------------
# Private Subnet
# ------------------------
resource "aws_subnet" "private" {
vpc_id= aws_vpc.main.id
cidr_block= "10.0.2.0/24"
availability_zone = "ap-south-1a"
tags = {
Name = "PrivateSubnet"
}
}
# ------------------------
# Route Table (Public)
# ------------------------
resource "aws_route_table" "public_rt" {
vpc_id = aws_vpc.main.id
route {
cidr_block = "0.0.0.0/0"
gateway_id = aws_internet_gateway.gw.id
}
tags = {
Name = "PublicRouteTable"
}
}
# ------------------------
# Route Table Association
# ------------------------
resource "aws_route_table_association" "public_assoc" {
subnet_id
= aws_subnet.public.id
route_table_id = aws_route_table.public_rt.id
}
# ------------------------
# Security Group
# ------------------------
resource "aws_security_group" "web_sg" {
name
= "web-security-group"
description = "Allow SSH and HTTP"
vpc_id
= aws_vpc.main.id
# SSH
ingress {
from_port = 22
to_port= 22
protocol= "tcp"
cidr_blocks = ["0.0.0.0/0"]
}
# HTTP
ingress {
from_port = 80
to_port= 80
protocol= "tcp"
cidr_blocks = ["0.0.0.0/0"]
}
# HTTPS
ingress {
from_port = 443
to_port= 443
protocol= "tcp"
cidr_blocks = ["0.0.0.0/0"]
}
# Outbound
egress {
from_port = 0
to_port=0
protocol= "-1"
cidr_blocks = ["0.0.0.0/0"]
}
tags = {
Name = "WebSecurityGroup"
}
}
Save:
CTRL + O → Enter → CTRL + X
3. Create outputs.tf
nano outputs.tf
Paste:
output "vpc_id" {
value = aws_vpc.main.id

output "public_subnet_id" {
value = aws_subnet.public.id
}
output "private_subnet_id" {
value = aws_subnet.private.id
}
output "security_group_id" {
value = aws_security_group.web_sg.id
}
Save.

terraform init
Expected:
Terraform has been successfully initialized

Expected:
Success! The configuration is valid.

•​aws_route_table
•​aws_security_group

terraform apply
Type:
yes
Wait until:
Apply complete!
8. Verify in AWS Console
Go to AWS Console → Amazon VPC
Check:
VPC
You should see:
Amazon Web Services VPC named MyVPC
Subnets
•​PublicSubnet
•​PrivateSubnet

# Subnet A

cidr_block= "10.0.1.0/24"
availability_zone

Name = "subnet-a"
}
}

resource "aws_vpc" "vpc_b" {
cidr_block = "192.168.0.0/16"

}

resource "aws_subnet" "subnet_b" {
vpc_id= aws_vpc.vpc_b.id
cidr_block= "192.168.1.0/24"
availability_zone
= "ap-southeast-2b"
map_public_ip_on_launch = true
tags = {
Name = "subnet-b"
}
}
# Peering
resource "aws_vpc_peering_connection" "peer" {
vpc_id
= aws_vpc.vpc_a.id
peer_vpc_id = aws_vpc.vpc_b.id
auto_accept = true
tags = {
Name = "peer-a-b"
}
}
# Route A -> B
resource "aws_route" "a_to_b" {
route_table_id
= aws_vpc.vpc_a.main_route_table_id
destination_cidr_block = "192.168.0.0/16"
vpc_peering_connection_id = aws_vpc_peering_connection.peer.id
}
# Route B -> A
resource "aws_route" "b_to_a" {
route_table_id
= aws_vpc.vpc_b.main_route_table_id
destination_cidr_block = "10.0.0.0/16"
vpc_peering_connection_id = aws_vpc_peering_connection.peer.id
}
